# AI Travel Product Management System

AI-powered Travel Product Management System built with React,
NestJS, PostgreSQL, Prisma and OpenAI.

## Tech Stack

- React
- TypeScript
- NestJS
- PostgreSQL
- Prisma
- OpenAI API
- Docker

## Current Features

- Product CRUD
- Product validation
- Product filtering
- Pagination
- Product validity handling
- Inventory availability handling
